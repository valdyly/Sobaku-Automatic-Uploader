# 🚀 Sobaku Automatic Uploader

Aplikasi otomatisasi (_desktop uploader tool_) yang dirancang untuk mempercepat dan mempermudah proses pengunggahan data/file secara terstruktur dan efisien.

---

## 📌 Fitur Utama

- **Otomatisasi Unggah:** Mengunggah berkas/data secara otomatis tanpa proses manual yang berulang.
- **Batch Processing:** Mampu menangani pengunggahan banyak file sekaligus.
- **Antarmuka Modern:** Tampilan intuitif dan responsif untuk kemudahan penggunaan.
- **Sistem Logging & Error Handling:** Memudahkan pelacakan status pengunggahan dan penanganan masalah secara _real-time_.

---

## 🛠️ Tech Stack

- **Frontend / Desktop Framework:** Electron.js / React.js / Node.js
- **Styling:** Tailwind CSS / Shadcn UI
- **Build Tool:** Vite
